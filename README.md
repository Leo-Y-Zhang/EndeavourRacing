# Mission Control — Endeavour Racing

Project management dashboard for Endeavour Racing, a six-student team from Harrow School competing in the STEM Racing Nationals 2026 (Development Class).

## Features

- **Overview** — KPI strip, milestone progress, workload distribution, activity log
- **Task Board** — Kanban-style task tracking across team members
- **Risk Register** — Risk identification, likelihood/impact matrix, mitigation tracking
- **Budget** — Expenditure tracking against budget categories
- **Schedule** — Season Gantt timeline and milestone tracking
- **KPI Tracking** — Live team performance indicators

## Running

No build step, no dependencies. Single self-contained HTML file.

```bash
# macOS / Linux — open in any browser
open index.html

# Windows — double-click start.bat, or from a terminal:
start index.html
```

Or double-click `index.html` (or `start.bat` on Windows) in File Explorer.

## Edit Mode

Click the **Edit** toggle in the top bar to make all fields inline-editable directly in the browser.
