# Endeavour Racing

Combined home for the Endeavour Racing team: the marketing **website**, the **Precision Lap**
timing + telemetry app, and the **Mission Control** dashboard. Each sub-project keeps its full
commit history (merged with git subtree).

## Sub-projects
- `website/`         - team marketing site (from EndeavourRacingWebsite)
- `precision-lap/`   - lap timing + driver performance app (from EndeavourPrecisionLap)
- `mission-control/` - project / task / risk / budget dashboard (from EndeavourMissionControl)
