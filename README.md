# Precision Lap — Endeavour Racing

Lap timing and driver performance prediction app for Endeavour Racing. Configure your car setup and get a predicted lap time based on tyre compound, fuel load, ERS deployment, and DRS usage.

## Features

- **Setup Configuration** — Choose tyre compound, fuel level, ERS mode, and DRS
- **Lap Time Prediction** — Real-time lap time estimate based on setup parameters
- **Driver Performance** — Sector breakdowns and performance visualisation
- **Animated UI** — Rain particle effects, scanline overlay, F1-style dark theme

## Running

No build step, no dependencies. Single self-contained HTML file.

```bash
# Just open in any browser
open index.html
```

Or double-click `index.html` in File Explorer.
